Run your whole stream from the Den

Alerts that fire on command, a branded overlay, and a ticker that reads your rules — all browser-source pages you paste into OBS or Streamlabs. No keys, no accounts. Works today.

🎛️ STEP 1 — CONFIGURE

Set your streamer name and ticker lines. These save to this browser and are sent live to every Den page you have open.

🔔 STEP 2 — FIRE ALERTS

Tap one while your browser-source Alerts page is running — it pops on stream with a sound. Name and message appear in the alert.

Broadcast range: same browser, same device, any tabs. Stream alerts from another device (or real platform events) arrive in Phase 2 when the Den backend comes online — the alert page is already built to receive them.

🛠️ STEP 3 — PUT THEM ON STREAM (OBS / Streamlabs)

  1. In OBS (or Streamlabs Desktop): Sources → + → Browser
  2. Name it Den Alerts, paste the Alerts link from Step 4, size 1920 × 1080
  3. Repeat for the Overlay link (corner badge + ticker)
  4. Keep this Command Center open in a browser tab on the streaming device — tap alerts live, mid-stream
  5. TIP: lock the browser layer in OBS so you don't click it on camera

Browsers on phone can't paste browser sources — drive the Den from the device you stream with (or the same device's browser). Phone control arrives with the Den backend.

🧰 STEP 4 — YOUR BROWSER-SOURCE LINKS

🔔Alerts page — copy this URL into OBS
 🖼️Overlay page — badge + scrolling ticker

Long-press each link (or right-click on desktop) → Copy address, then paste into OBS. The commands above also write your name/ticker into these pages automatically.
